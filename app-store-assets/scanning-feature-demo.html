GoutGuard Nutrition Label Scanning Feature

Demo walkthrough for App Store Review - Submission ID: 2b6263e9-18cf-4e62-9d7c-92a8d7e016ee

Feature Overview

The scanning feature allows users to photograph nutrition labels on food packaging and receive an AI-powered safety analysis. The feature analyzes:

  • Purine content assessment for gout management
  • Sodium levels for overall health monitoring
  • Key nutrients identification from the label
  • Ingredients analysis for dietary concerns
  • Overall dietary recommendation
1
Home Screen - Upload Nutrition Facts
The user opens the app and sees the main analysis screen. A medical disclaimer banner is always visible at the top. The upload zone accepts photos via camera (tap to open camera) or photo library. Users can also drag and drop images on iPad. Up to 4 images can be uploaded (e.g., nutrition facts panel + ingredients list from the same product).
2
Capture / Select Nutrition Label Photos
The user taps the upload zone, which opens the iOS photo picker or camera. They can photograph:
- The Nutrition Facts panel on food packaging
- The Ingredients list on the back of the package
- Up to 4 images for a single analysis

The app uses the standard HTML file input with accept="image/*" which triggers the native iOS photo picker with camera option.
3
AI Analysis in Progress
After tapping "Check Food Safety", the images are sent to the server where Claude's vision API analyzes the nutrition label content. A loading spinner is shown during analysis.
4a
Results - Safe Food
When a food is determined to be generally safe, a green "Generally Safe" verdict is displayed along with:
- A summary of the assessment
- Key nutrients identified from the label
- Ingredients analysis
- Specific dietary concerns
- Overall recommendation
4b
Results - Caution / Avoid
When the analysis detects concerning ingredients, a yellow "Caution" or red "Avoid" verdict is displayed with detailed analysis explaining the concerns and recommendations.

Technical Implementation

The scanning feature uses:

  • Image capture: Standard HTML5 file input with accept="image/*" - triggers the native iOS camera/photo picker
  • Image processing: Images are converted to base64 and sent to the server API
  • AI Analysis: Claude's vision API reads and interprets the nutrition label
  • Results: Structured verdict (safe/caution/avoid) with detailed analysis sections

Camera Permissions

The app declares the following permissions in Info.plist:

  • NSCameraUsageDescription: Camera access to photograph nutrition labels for analysis
  • NSPhotoLibraryUsageDescription: Photo library access to select nutrition label images for analysis
